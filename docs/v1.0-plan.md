# Road to v1.0

Status date 2026-11-20 (after v0.4.1). Source of truth for open work stays `TASKS.md`; this note sorts every open item by who can close it, and proposes what v1.0 means. **The scope below is a proposal; the owner decides (item D1).**

## Proposed definition of v1.0
v1.0 is the first release where (1) all 11 MVP criteria in the README pass on the physical board with recorded evidence (`docs/mvp-acceptance.md`), (2) a release package built from the tagged commit contains the CPU+peripheral image, the CPU-less card image, boot firmware, kernel, DTB, rootfs, manifest, checksums and recovery procedures, and (3) the interfaces other projects build on are frozen and documented: the card BAR0 map (`card_regs`, `user_regs`, `user_ip` windows, `pcie_regs`), the rig line protocol, the `build_soc.tcl` options, and the PCIe identity manifest. Out of v1.0 (stay in "Deferred workstreams"): FMC, the 100G optical port, an auxiliary microcontroller core, security hardening and signed boot.
